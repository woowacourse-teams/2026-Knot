## 구현 기능 설명

GitHub OAuth 신규 사용자는 닉네임 입력을 완료한 뒤에만 Member를 한 명 생성한다. 가입
세션이 유효하면 닉네임 입력을 다시 시도하고, 만료되면 OAuth부터 다시 시작한다.

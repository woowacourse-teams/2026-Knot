# LLM 주제 분류 실험

관련 이슈: #521 공통 LLM API 연동·전사 원문 주제 분류.

[#521 실제 API 관찰](521-topic-classification-2026-10-08.md)에 합성 입력·요청값·실제 출력·판정 기준과 한계를 기록한다. 제품 프롬프트는 [classpath 리소스](../../backend/src/main/resources/llm/document/topic-classification-system.txt)를 기준으로 한다.

문서 작성·발언 선별 실험과 작성 프롬프트 버전은 #522·PR #535에서 관리한다. 작성 실험 횟수와 결과를 #521의 분류 품질 근거로 계산하지 않는다.

인증값·실제 회의 원문·실험 코드는 저장하지 않는다. 대상 주소는 환경변수로 치환한다. JSON 계약 통과, 의미 품질, 동일 입력 회귀, 운영 배포 검증을 구분하고 실패 출력도 그대로 보존한다.

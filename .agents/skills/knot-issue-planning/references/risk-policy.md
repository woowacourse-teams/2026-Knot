# 위험 분류 정책

다음 신호 중 하나라도 있으면 Harnessed 경로를 사용한다.

| 신호 | 코드 값 |
| --- | --- |
| 데이터 구조, 마이그레이션, 보존·삭제 정책 | `data` |
| 로그인, 인증·인가, 보안, 개인정보 | `security` |
| 외부 API, OAuth, 결제, 장기 의존성 | `external` |
| FE–BE 요청·응답·오류·상태 계약 | `cross-boundary` |
| 가입, 탐색, 동기화 등 핵심 사용자 흐름 | `core-flow` |
| 여러 도메인·모듈·팀 규칙에 반복 영향 | `shared` |
| 롤백이 어렵거나 실패 비용이 큼 | `hard-to-reverse` |

명확한 오탈자, 국소 버그, 테스트 보강과 제한적인 문서 수정은 신호가 없는 Lightweight
작업으로 처리한다. AI는 코드 값과 함께 실제 분류 근거를 Issue 계약에 기록한다.

# Grill 검사 범주

- 더 작은 검증으로 해결할 문제를 구현으로 확대했는가
- 정상 흐름만 있고 오류·취소·재시도·중복·동시성 흐름이 빠졌는가
- 인증·권한·개인정보·보존·삭제 정책이 빠졌는가
- FE와 BE가 서로 다른 상태나 오류 계약을 가정하는가
- 외부 장애, timeout, rate limit과 부분 실패를 고려했는가
- 성공 기준이 주관적이거나 어떤 결과도 성공으로 해석 가능한가
- 롤백, 운영 관측과 장애 복구가 빠졌는가
- 기존 코드, ADR 또는 정본 문서와 충돌하는가

치명적 질문은 답이 없으면 구현을 시작할 수 없는 질문이다. 단순 선호, 변수명과 내부
구조 선택은 치명적 질문으로 취급하지 않는다.

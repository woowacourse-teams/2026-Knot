## 할 일

내용이 없는 섹션은 heading까지 생략한다. "없음", "해당 없음", 빈 목록을 쓰지 않는다.
각 항목은 원문의 사실과 조건을 보존한다. 보류 항목 끝에는 회의에서 말한 실행 조건·시점을 붙인다.
고정 섹션 뒤에는 회의 내용에 맞는 추가 H2 heading(배경, 이유, 우려, 대안, 제안 등)을 직접 골라 이어 쓴다.
H1 문서 제목은 content에 넣지 않는다. title은 별도 JSON 필드다. 안내 문장이나 템플릿 경로도 결과에 넣지 않는다.

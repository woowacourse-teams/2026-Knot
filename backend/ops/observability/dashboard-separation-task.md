# Dev·Prod 전용 대시보드와 로그 화면 분리

- 사용자 요청: 환경을 함께 보는 화면이 어려우므로 Dev와 Prod를 별도 대시보드로 나누고 로그 조회 위치를 명확하게 만든다.
- 범위: 기존 Grafana 기본 패널을 재사용한 Dev 7개 / Prod 5개 화면, 환경 고정 조회, 전용 탐색 링크, 짧은 설명과 로그 전용 화면.
- 시각화: 현재 상태 Stat, 자원 사용률 Gauge, 추세 Time series, health 이력 State timeline, 경로별 오류 Table, 원문 Logs, Dev Spring 실제 histogram Heatmap.
- 후속 요청: Discord 제목·본문을 환경·문제·감지·확인·시각·바로가기로 바꾼다. 발생/해제/테스트를 구분하되 기존 알림 조건과 라우팅은 유지한다.
- 기존 자산: 공통 6개 UID와 알림 패널 연결, 수집기·보존·인증·앱·DB 설정은 유지한다.
- 검증: 환경 격리, 로그 소스 분리, Prod Spring 패널 제외, UID·링크·배치·파일 프로비저닝 경로, 생성 결과 일치, 알림 표시 연결과 감지 계약 보존. 실제 Grafana 렌더링과 Discord 테스트 수신은 별도 검증한다.
- 제한: 저장된 사이트 접근 차단을 우회하지 않는다. 로컬 설정 검증과 실제 서버 반영·렌더링 검증은 별도로 기록한다. 서브에이전트는 사용하지 않는다.

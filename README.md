# Knot

Knot 프로젝트의 코드와 개발 협업 기록을 관리하는 저장소입니다.

## 시작하기

- 백엔드 프로젝트: [`backend/`](backend/)
- 기여 절차: [`CONTRIBUTING.md`](CONTRIBUTING.md)
- 협업 흐름: [`docs/collaboration/workflow.md`](docs/collaboration/workflow.md)
- 작업 준비·완료 기준: [`docs/collaboration/definition-of-ready-done.md`](docs/collaboration/definition-of-ready-done.md)
- 작업 인계 양식: [`docs/collaboration/context-handoff.md`](docs/collaboration/context-handoff.md)
- 명세 관리 원칙: [`docs/specs/README.md`](docs/specs/README.md)

## 협업 현황

- 작업 상태와 완료 조건: [GitHub Issues](https://github.com/woowacourse-teams/2026-Knot/issues)
- 초기 협업 기반 구축: [M0 - Collaboration Bootstrap](https://github.com/woowacourse-teams/2026-Knot/milestone/2)
- Notion 가져오기 핵심 기능: [M1 - Notion Import Core](https://github.com/woowacourse-teams/2026-Knot/milestone/1)

GitHub는 작업 상태, Notion은 제품 맥락과 탐색 포털, 저장소의 ADR은 기술 결정 기록을 담당합니다. 자세한 책임 경계는 [협업 흐름](docs/collaboration/workflow.md#도구별-source-of-truth)에서 확인합니다.
